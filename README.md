# AquaTerra — септик без откачки (Нижний Новгород и область)
Лендинг: станции биологической очистки «Тверь» (Баланс 4К, Классик 0.5), обустройство скважины. index.html, styles.css, script.js, privacy.html, assets/.
Заявки уходят через lead-relay (ref 4QPCXH8UND). В заявку добавляются интерес, ползунок воды и расчёт откачки, если ими пользовались.
`?motion` в URL включает анимации при prefers-reduced-motion (для проверки).
Фото: lids-lawn (Wikideas1, CC0), trench-water (Jonathan Billinger, CC BY-SA 2.0, geograph), excavator (NCDOT, CC BY 2.0), trench-lids — из группы клиента ВКонтакте. Заменить на съёмки своих объектов.
